# 캡스톤디자인 경진대회 평가시스템

명지전문대학 2026학년도 캡스톤디자인 경진대회(2026. 11. 19.–20.)의 온라인 심사 프로그램입니다.
단일 HTML 파일이며 claude.ai 아티팩트 안에서 실행됩니다(`window.claude`의 db·user·downloads 기능 사용). 브라우저에서 파일을 직접 열면 저장소에 연결되지 않습니다.

## 주요 기능
- 평가위원 로그인: 성명 + 전화번호(번호 원문은 저장하지 않고 SHA-256 값만 대조)
- 심사 입력: 4개 영역 10개 항목(각 5~10점), 미참여 시 전 항목 5점 자동, 동시 저장 감지
- 집계: 학부별 순위, 위원 간 점수 차 15점 이상 표시, 엑셀 내보내기
- 수상 배정: 학부별 정원, 동점자 처리(평균 → 기술성·완성도 소계 → 창의성·기획성 소계), 대상 1팀 및 해당 학부 상격 상향, 미참여 팀 수상 제외
- 마감 후 출력: 2025학년도 서식의 심사표 PDF(위원별·팀별·전체), 상장 PDF·머지용 엑셀
- 관리자: 심사 마감, 수상 정원, 위원 전화번호 등록, 위원별 점수 초기화, 심사위원 변경(대리 열람·입력)

## 데이터
심사위원·팀·점수 데이터는 저장소에 포함하지 않습니다(아티팩트 DB에 보관).
- `config/main`: 위원 목록(phoneHash 포함), 마감 여부, 수상 정원
- `teams/{부스}`: 팀 정보
- `scores/{위원ID}__{부스}`: 항목별 점수

## 포함하지 않은 파일
- `cert-seal.png`(상장 직인 이미지): 학교 직인이므로 저장소에 올리지 않았습니다. 상장 출력에 필요하면 아티팩트에 함께 게시하세요.

## 알려진 한계
위원별 쓰기 권한과 마감은 화면에서만 강제됩니다. 서버 측 권한(RLS)은 Supabase·Vercel 재구축 시 적용 예정입니다.
